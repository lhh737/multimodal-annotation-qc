# 人工与模型标注对比

数据：21 条文本正式样本，裁决金标。
标注员：人工 ann1、DeepSeek-V4-Flash、GLM-5.3。

## 结论

1. 模型之间一致性很高（κ 0.929），人机一致性中等（人工 vs DeepSeek 0.634，人工 vs GLM 0.701）。
2. 以裁决金标计，DeepSeek 21/21 正确，GLM 20/21，人工 16/21。
3. 人工错误全部集中在边界样本：广告、超短、混合情感、平淡陈述、隐私文本。
4. 模型置信度几乎全在 4–5，无法用置信度筛出错误；人工置信度 4 的准确率只有 62.5%。

这组结果说明模型可以承担预标注和分歧提示，但不能直接替代人工裁决。模型在 system prompt 中获得了完整规范，人工只阅读了文档，两者条件并不对等，不能据此推断模型标注能力全面更强。

## 错误明细

| 任务 | 文本 | 金标 | 人工 | DeepSeek | GLM |
|---|---|---|---|---|---|
| T04 | 加微信领红包… | 无法判断 | 中性 | ✓ | ✓ |
| T05 | 还行。 | 中性 | 正面 | ✓ | ✓ |
| T11 | 味道不错，但贵… | 正面 | 中性 | ✓ | ✓ |
| T20 | 分量一般，味道一般… | 中性 | 负面 | ✓ | ✓ |
| T22 | 地址 + 手机号 | 中性 | 正面 | ✓ | 正面 |

T22 同时是人工和 GLM 的错误，但方向不同：人工把它当作正面服务体验，GLM 把“直接送上来了”理解为正向；DeepSeek 判为中性。

## 置信度校准

| 标注员 | 置信度 5 | 4 | 3 | ≤2 |
|---|---:|---:|---:|---:|
| 人工 ann1 | 90.9% (11) | 62.5% (8) | 0% (1) | 100% (1) |
| DeepSeek-V4-Flash | 100% (12) | 100% (9) | — | — |
| GLM-5.3 | 100% (10) | 100% (9) | 50% (2) | — |

人工的高置信度并不稳定；模型的置信度缺少区分度。若用于预标注，应优先复核模型之间不一致的样本，而不是只看模型自报置信度。

## 解释与限制

- **条件不对等**：模型 prompt 含完整规范，人工只阅读文档。模型的高准确率至少部分来自“规范被直接放进上下文”。
- **样本小**：21 条正式样本，κ 和准确率的置信区间较宽。
- **单一人工**：人工只有 ann1，无法区分“个人偏差”和“标注员普遍偏差”。
- **金标来源**：金标由同一名项目作者按规范裁决，可能存在确认偏差。
- **模型差异**：两个模型来自不同 provider，解码参数只统一了 temperature=0，其他参数未做严格控制。

因此，这组数据适合用来演示评测流程和定位边界样本，不适合作为模型能力的排名依据。
