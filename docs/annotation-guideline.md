# 标注规范

**版本** 1.1 · 2026-10-20
**适用** 中文外卖评论情感/方面标注、图像目标框、语音转写质检

本规范的目标不是描述“什么是好评”，而是让不同标注员对同一条数据给出可复核的一致判断。规则按优先级执行，遇到冲突时以序号靠前的条款为准。

---

## 1. 文本标注

### 1.1 字段

| 字段 | 类型 | 取值 | 必填 |
|---|---|---|---|
| sentiment | 单选 | 正面 / 负面 / 中性 / 无法判断 | 是 |
| aspects | 多选 | 口味 / 配送 / 价格 / 服务 / 卫生 / 包装 / 无 | 否 |
| flags | 多选 | 广告推广 / 含隐私信息 / 表述不清 / 疑似模板或刷单 / 无 | 否 |
| confidence | 单选 | 1–5 | 是 |

### 1.2 情感判定顺序

1. 广告、无关内容、无意义符号 → **无法判断**。
2. 有明确结论句 → **按结论句**。
3. 正负证据相当、态度平淡 → **中性**。
4. 核心体验严重受损（送错、洒漏、严重超时、卫生问题）→ **负面**。
5. 其余 → **正面**。

不要逐词做情感分析，也不要根据常识替商家补充文本没有表达的态度。

### 1.3 混合情感与反讽

- 有结论句时，结论句优先于前面的细节。
- 没有结论句时，比较正负证据的严重性，而不是数正负词的数量。
- 反讽按真实语义判断，不按字面。
- 轻微抱怨不影响总体好评，判正面；核心体验受损，判负面。

### 1.4 边界条款（v1.1 新增）

以下五类是本轮试标和复核中实际出现分歧的样本，v1.1 将其写成明确条款：

| 情形 | 判定 | 附加要求 |
|---|---|---|
| 广告、引流、联系方式 | 无法判断 | flags 必须含“广告推广” |
| 超短文本（如“还行。”） | 中性 | 能推断态度时按语义，不能推断时判无法判断 |
| 仅陈述地址、电话、门牌号 | 中性 | flags 必须含“含隐私信息” |
| 全部为“一般”“没什么特别” | 中性 | aspects 选“无” |
| 正负陈述自相矛盾 | 无法判断 | 无法确定最终态度时使用 |

隐私信息只做标记，不在备注或报告中复述完整手机号、门牌号；对外展示时脱敏为 `138****5678`。

### 1.5 方面

只标文本中明确提到的方面，不从情感标签反推。

| 方面 | 线索 |
|---|---|
| 口味 | 好吃、难吃、咸、辣、油腻、凉了、味道 |
| 配送 | 快、慢、超时、骑手、送到、洒了 |
| 价格 | 贵、便宜、性价比、多少钱、分量（与价格一起提及时） |
| 服务 | 态度、打电话、催单、退款、客服 |
| 卫生 | 头发、异物、脏、不新鲜 |
| 包装 | 包装、餐盒、袋子、密封、洒漏 |
| 无 | 没有任何具体方面 |

规则：

- 可多选；“无”与其他方面互斥。
- “凉了”明确由配送导致时标配送，未说明原因时标口味。
- 单纯说“分量大/小”标口味；与价格、划算一起出现时标价格。

### 1.6 质量标记

| 标记 | 判定 |
|---|---|
| 广告推广 | 联系方式、二维码、引流、招兼职、与消费无关的推广 |
| 含隐私信息 | 真实姓名、手机号、门牌号、身份证号、车牌 |
| 表述不清 | 语义无法理解、大量错别字导致歧义、纯符号 |
| 疑似模板/刷单 | 高度模板化、重复句式、与商品无关的空泛好评 |
| 无 | 以上都没有 |

“无”与其他标记互斥。

### 1.7 置信度

| 分值 | 含义 |
|---|---|
| 5 | 语义明确，换个人也会同意 |
| 4 | 有小歧义，但倾向明显 |
| 3 | 需要按规范推理，存在另一种合理解释 |
| 2 | 规范未覆盖，凭经验判断 |
| 1 | 信息严重不足，接近猜测 |

置信度用于复核路由，不参与金标。要求如实填写；虚报 5 分会破坏校准分析。

## 2. 图像标注

1. 框紧贴目标外接矩形，不留大边距，不切掉主体。
2. 每个目标一个框；同一目标不重复框。
3. 类别：人、动物、车辆、食物、其他。
4. 小于图像面积 1% 的目标不框；可见面积不足 30% 的遮挡目标不框。
5. 图片质量单选：清晰可标 / 部分遮挡 / 模糊过暗 / 无可标目标。
6. 无可标目标时提交空标注，并在质量项选择“无可标目标”。

## 3. 语音转写质检

1. 以听感为准，必须完整回听，不参照 ASR 文本猜测。
2. 保持原语序和原用词；只改错听部分，不润色、不改写、不补全。
3. 数字、专名、英文按音频实际发音转写；无法确定时保留 ASR 写法并标注错误类型。
4. 标点按语义补全；句中标点可简化。
5. 听不清用 `[听不清]` 占位，不编造；最多回听 3 次。
6. 错误类型：多字 / 漏字 / 错字或同音字 / 专有名词 / 标点格式 / 无错误。
7. 可懂度 1–5：5 完全可懂，1 无法转写。

**评分口径**：CER 计算前做数字归一化，“二十四”与“24”视为同一写法；标点不计入错误。

## 4. 流程与质检

| 阶段 | 要求 |
|---|---|
| 试标 | 8–10 条，覆盖每个标签至少 2 次；试标不计入正式一致性 |
| 正式标注 | 至少 2 名标注员独立标注同一批任务，互不讨论 |
| 复核 | 100% 输出分歧任务；低置信度（≤3）100% 复核 |
| 裁决 | 对照规范给出最终标签与理由；规范未覆盖的补充条款并记版本 |

一致性指标：

| 指标 | 用途 | 参考 |
|---|---|---|
| 两两一致率 | 直观，但未校正随机一致 | 仅作辅助 |
| Cohen's κ | 两名标注员 | > 0.80 较好 |
| Fleiss' κ | 多名标注员、任务完整 | > 0.80 较好 |
| Krippendorff's α | 允许缺失值 | > 0.80 较好 |
| F1 @ IoU≥0.5 | 图像框匹配 | > 0.90 较好 |
| CER | 语音转写 | 越低越好 |

阈值不是硬标准，需结合任务难度和样本量解释。
